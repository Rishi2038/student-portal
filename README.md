# Student Details & Attendance Management Portal

A fullstack web application for student record management, attendance tracking, CGPA monitoring, and role-based portal access.

## Features

- **Dual-Role Authentication**:
  - **Admin Login**: Username `admin` & Password `admin123`. Full access to register, update, and delete student records.
  - **Student Login**: Roll Number as ID and password (either generated by Admin or set by student).
- **Admin Dashboard**:
  - Batch performance metrics (Total students, average attendance %, average CGPA, low attendance alert count).
  - Student directory with live search and attendance threshold filtering.
  - "Add Student" modal with built-in **Random Password Generator** and 1-click clipboard copy.
  - Edit modal for CGPA, attendance, department, and password resets.
  - Delete student modal with instant removal.
- **Student Portal**:
  - Personal profile with Name, Roll Number, Department, and Avatar.
  - **Attendance Record**: High-visibility percentage gauge, exam eligibility status (&ge; 75% threshold), and attended vs missed class breakdown.
  - **Academic Performance**: CGPA score (out of 10.0), scale bar, and grade classification (Outstanding, Excellent, Very Good, etc.).
  - Self-service password change option.
- **Zero-Setup Database**: Built with Node.js native SQLite (`students.db`), ensuring local persistence without external database servers.

## Getting Started

### 1. Requirements
- Node.js v22 or higher (tested on Node.js v24).

### 2. Start the Application
Run from this directory:
```bash
node server.js
```
The server will start at:
```
http://localhost:3000
```

### 3. Run Automated Tests
```bash
node test-api.js
```
